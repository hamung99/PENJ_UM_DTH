Catatan cara kerja: setiap slot (Sumber A / Sumber B) menyimpan hasil upload TERAKHIR saja — kalau besok Anda upload file baru ke slot yang sama, data lama di slot itu otomatis tergantikan, tidak akan menumpuk/dobel. Anda juga bisa menambah data satu per satu lewat menu Input AR Minyak / Input AR Rupa‑rupa (data manual digabung ke slot yang sama). Kategori dibaca dari kolom STATUS dan TOTAL PAYMENT: Sudah Lunas = status "SUDAH LUNAS", Bayar Titip = masih piutang tapi sudah ada pembayaran sebagian, Belum Lunas = masih piutang dan belum ada pembayaran sama sekali. Semua proses dilakukan di komputer Anda sendiri (di dalam browser) — file tidak dikirim ke server manapun. Data hasil upload & input manual disimpan otomatis di browser (IndexedDB), jadi tetap ada meski halaman di-refresh — baru hilang kalau Anda klik "hapus" pada slot, atau membuka dashboard ini dari browser/komputer lain. Parsing file Excel besar dilakukan di Web Worker agar UI tidak freeze. Tabel menggunakan pagination.
